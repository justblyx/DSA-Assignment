## Program Details

Topic: Interplanetary Navigation System

## Folder Structure

The workspace contains two folders by default, where:

- `src`: the folder to maintain source code
- `javafx`: the folder to maintain dependencies for javafx

Meanwhile, the compiled output files will be generated in the `bin` folder by default.


## Program Requirements

Your program should support the following functionalities:
(a) Create the graph
    (i) Add Vertex
    (ii) Remove Vertex
    (iii) Add Edge
    (iv) Remove Edge
(b) Traversal of the graph (BFS)
(c) Display of the Graph
